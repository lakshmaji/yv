Add a Settings → Sharing option for how often a nearby device has to type the connection code: every time (the default, unchanged), once per running session, or never.

"Once" and "never" trade away the guarantee the code exists for — that a real person, not just anyone on the same Wi-Fi, authorized the connection — so they are opt-in and the settings description says so. Peer identity is not persisted across a restart, so "once" only ever remembers a peer for as long as the app keeps running.
